# Aula de Front-End — HTML, CSS e JavaScript

Projeto básico para ensinar os três pilares da web, com código comentado em português.

## Estrutura

```
frontend-html-css-js/
├── index.html       # Estrutura da página (HTML)
├── css/
│   └── estilos.css  # Estilo da página (CSS)
└── js/
    └── script.js    # Comportamento/interatividade (JavaScript)
```

## Como usar

Não precisas de instalar nada. Basta abrir o `index.html` diretamente no browser (duplo clique, ou "Abrir com" > browser).

Para uma melhor experiência de edição (recarregar automaticamente ao gravar), podes usar a extensão **Live Server** no VS Code:

1. Instala a extensão "Live Server" no VS Code.
2. Clica com o botão direito em `index.html` > "Open with Live Server".

## Como editar/experimentar

- **HTML** (`index.html`): muda textos, adiciona novos elementos, cria novas secções.
- **CSS** (`css/estilos.css`): muda cores, tamanhos, espaçamentos, tipo de letra.
- **JS** (`js/script.js`): muda o comportamento dos botões ou cria novas funcionalidades.

Depois de gravares qualquer ficheiro, basta recarregar o browser (F5) para ver o resultado.

Há desafios sugeridos no fim do ficheiro `js/script.js` para os alunos experimentarem.
